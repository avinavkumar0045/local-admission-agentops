1. EXECUTIVE SUMMARY
--------------------------------------------------------------------------------
The AgentOps Local RAG Project is a fully functional, locally hosted AI assistant designed to answer university admission queries. The core objective of the project was "Instrumentation-by-Design," ensuring that every action taken by the AI is meticulously monitored, timed, and recorded via OpenTelemetry for observability and evaluation. 

2. TECHNOLOGY STACK
--------------------------------------------------------------------------------
- Large Language Model: Qwen 2.5 Coder (4.7GB, running locally via Ollama)
- Vector Database: FAISS (Facebook AI Similarity Search)
- Embedding Model: sentence-transformers (all-MiniLM-L6-v2)
- Backend API: FastAPI (Python 3.13)
- Frontend UI: Streamlit (with custom CSS)
- Observability Backend: Grafana Tempo & OpenTelemetry Collector (Docker)
- Legacy Telemetry DB: MySQL (Homebrew local service)
